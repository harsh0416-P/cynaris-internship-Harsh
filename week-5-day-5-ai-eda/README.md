

\# W5D5 — AI-Powered EDA on an Indian Business Dataset



\## Objective

Build an exploratory data analysis pipeline for a 100,000-row sales dataset using Python.



\## Features

\- Data-quality checks for missing values and duplicate rows

\- Summary statistics

\- Revenue analysis by city and category

\- Product quantity analysis

\- Four visualizations

\- Cross-validation of key metrics using DuckDB SQL

\- Rule-based business insights report



\## Technologies

Python, Pandas, Matplotlib, DuckDB, CSV, Git.



\## Dataset

Reuses the sales CSV generated in W5D3:



`../week-5-day-3-duckdb/data/sales.csv`



\## Run

Activate the repository virtual environment and run:



```bash

python main.py

python ai\_analysis.py

```



\## Outputs

The `outputs/` folder contains:

\- `data\_quality\_report.json`

\- `summary\_statistics.csv`

\- `revenue\_by\_city.csv`

\- `revenue\_by\_category.csv`

\- `quantity\_by\_product.csv`

\- `eda\_findings.md`

\- `ai\_analysis\_results.md`

\- `charts/` with four PNG charts



\## AI limitation

The current business insights report uses deterministic Python and Pandas rules. It is not generated by an LLM. PandasAI 2.3.2 is available in a separate Python 3.11 environment, but live LLM integration has not been configured because an API key is unavailable.



\## Validation

The key revenue, average sale, and high-value transaction metrics are checked against DuckDB SQL results in `main.py`.
