# Stakeholder Sharing Guide
## Indian Business Analytics Dashboard

### 1. Dashboard Overview

Dashboard Name: Indian Business Analytics Dashboard

Platform: Metabase

Database: Indian Business Analytics

Source Table: Indian Business Data

The dashboard provides stakeholders with an overview of Indian property listings through five visualizations.

### 2. Dashboard Contents

1. Property Listings by City
   - Displays the number of property listings across cities.
   - Helps identify the distribution of listings by location.

2. Average Days on Market by Month
   - Displays the monthly average number of days properties remain on the market.
   - Helps identify changes in market activity over time.

3. Property Distribution by Transaction Type
   - Shows the distribution of property records by transaction type.
   - Helps stakeholders compare transaction categories.

4. Property Listings Detailed Table
   - Displays detailed property records and selected attributes.
   - Supports record-level analysis.

5. Total Property Listings
   - Displays the total number of property records.
   - Provides a quick overview of dataset size.

### 3. How Stakeholders Can Access the Dashboard

1. Open the Metabase application.
2. Sign in using an authorized account.
3. Navigate to the collection named W11D4 - Indian Business Analytics.
4. Open Indian Business Analytics Dashboard.
5. Review the available charts and table.

### 4. Sharing and Access Control

- Share dashboard access only with authorized stakeholders.
- Configure collection permissions through Metabase administration.
- Give viewers read-only access where appropriate.
- Give editing permissions only to users responsible for maintaining the dashboard.
- Do not share database credentials.
- Do not enable public dashboard sharing unless explicitly approved.

### 5. Dashboard Usage

Stakeholders can use the dashboard to:

- Compare property listings across cities.
- Review monthly changes in average days on market.
- Understand transaction-type distribution.
- Inspect individual property records.
- Monitor the total number of listings.

### 6. Data and Maintenance

- The dashboard uses the Indian Business Data table.
- The current dataset contains 600 records.
- Refresh or synchronize the underlying data when updated records become available.
- Review saved questions if the database schema changes.
