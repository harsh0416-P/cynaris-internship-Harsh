\# Week 5 Day 2: AutoViz \& SweetViz



\## Objective

Automate Exploratory Data Analysis (EDA) using AutoViz and SweetViz.



\## Dataset

Indian Air Quality dataset: 3,752 rows and 11 columns.



\## Technologies

\- Python

\- Pandas

\- AutoViz

\- SweetViz

\- Matplotlib

\- HTML reports

\- Git and GitHub



\## Findings

\- The dataset contains 3,752 rows and 11 columns.

\- pollutant\_min has 308 missing values.

\- pollutant\_max has 308 missing values.

\- pollutant\_avg has 308 missing values.



\## Reports

\- SweetViz: reports/sweetviz\_report.html

\- AutoViz charts: outputs/AutoViz/



\## Comparison

SweetViz provides a consolidated HTML report with feature statistics and distributions. AutoViz generates separate visualizations such as distribution plots, heatmaps, violin plots, and pair scatter plots. SweetViz is convenient for business stakeholders who prefer a single report, while AutoViz helps analysts explore multiple visualizations.



\## Limitation

AutoViz initially encountered a duplicate-column naming issue. Renaming the pollutant columns allowed the report generation to complete.
