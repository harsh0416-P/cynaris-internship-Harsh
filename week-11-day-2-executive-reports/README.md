\# Week 11 Day 2 — Executive Reporting



\## Overview

Transformed the Indian Business Dataset from Week 11 Day 1 into an executive reporting workflow.



\## Objectives

\- Calculate executive KPIs.

\- Build interactive Plotly visualizations.

\- Analyze numerical correlations.

\- Review outlier analysis.

\- Generate an executive PowerPoint report.



\## Tools Used

\- Python

\- Pandas

\- NumPy

\- Plotly

\- python-pptx

\- Jupyter Notebook

\- Git and GitHub



\## Project Structure

\- notebooks/ — Analysis notebook

\- charts/ — Interactive Plotly charts

\- reports/ — KPI summaries, findings and PowerPoint report

\- evidence/ — Project screenshots



\## Deliverables

\- W11D2\_Executive\_Reports.ipynb

\- Interactive HTML charts

\- Executive KPI CSV

\- Executive findings

\- Correlation matrix

\- W11D2 PowerPoint report



\## Learning Outcomes

Practiced converting exploratory data analysis into executive-friendly visual reports and automating PowerPoint generation with Python.



\## Limitation

Automatically selected columns and generated KPIs must be reviewed for business relevance before making business decisions.
