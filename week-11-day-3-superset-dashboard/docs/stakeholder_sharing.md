# Stakeholder Dashboard Sharing

## Dashboard
Indian Real Estate Stakeholder Dashboard

## Purpose
Provides stakeholders with an overview of property listings, average property prices, city-level price comparisons, property-type distribution, and listing details.

## Visualizations
- Total Property Listings — KPI
- Average Property Price — KPI
- Average Property Price by City — Bar Chart
- Property Type Distribution — Pie Chart
- Property Listings Detail — Table

## Sharing and Access Control
- Share the dashboard URL with authorized stakeholders.
- Grant access through Superset roles and permissions.
- Provide read-only access to viewers.
- Restrict dataset and SQL editing permissions to authorized analysts.
- Do not share administrator credentials.

## Limitations
The monthly listing trend chart remains incomplete. Dashboard figures reflect the available dataset and should not be treated as live market statistics.

## Stakeholder Value
The dashboard helps stakeholders compare property prices, understand listing composition, and inspect individual property records.
